# IC 电路分层学习 Skill

一套面向模拟与混合信号集成电路学习的 Agent Skill。它帮助你从“这个电路做什么”开始，结合网表、原理图、symbol、接口声明和仿真波形，逐步理解模块功能或关键晶体管机制，并按需设计仿真、整理 Markdown 学习卡片。

> 目标是帮助理解电路与已有证据；学习结论不等同于设计签核、全 PVT 验证或流片结论。

## 适用场景

- 想先弄清一个子电路的用途、输入输出和它在系统中的位置。
- 想沿着网表和连接关系理解模块怎样工作，或从晶体管级学习少数关键机制。
- 需要配置 Cadence Virtuoso / Spectre 的电源、时钟、使能和 PWL 激励。
- 想分析仿真波形、记录已验证条件，或生成便于复习的 Markdown 学习卡片。

既支持**粗学习**（功能、接口、关键路径和必要验证），也支持**精学习**（深入理解选定的核心子电路或晶体管机制）。不会默认逐管讲解，也不会把所有建议实验变成必做项。

## 使用方式

在支持 Agent Skills 的环境中加载本 Skill，然后用自然语言描述目标并提供手头已有的资料。也可以直接用下面的提示：

- 使用 $learn-ic-circuits，先粗学习这个电路，告诉我它的作用和接口。
- 使用 $learn-ic-circuits，从晶体管级带我理解这个锁存器最关键的保持机制。
- 用 $learn-ic-circuits 帮我为这个电路配置仿真激励，并说明每个源的参数。
- 根据我们已经确认的结论，用 $learn-ic-circuits 整理一份精简的 Markdown 学习卡片。

可提供的资料包括：网表、原理图截图、symbol、顶层 subckt 端口声明、仿真设置、波形截图，或已经确认的学习结论。先提供当前问题所需的资料即可，不必一次性准备全部内容。

## 学习流程

1. **确定对象与深度**：判断当前适合模块级粗学习，还是需要深入到核心子电路/晶体管级；已明确的目标直接继续。
2. **说明作用与接口**：先用白话解释“什么输入或使能出现后，电路做什么，输出何时变化，系统为什么需要它”。接口按输入、输出、电源与激励源分类。
3. **沿连接解释实现**：模块级跟踪信号路径与关键状态；晶体管级聚焦两三个关键机制，用导通路径、节点变化和反馈/保持关系解释因果。
4. **按需配置验证**：明确仿真目标、具体源类型与参数、使能状态、观测信号和判据。只有在延迟、负载、最高频率或 PVT 等结论需要证据时才安排对应实验。
5. **对照证据收尾**：区分结构推导、用户报告和实际仿真结果；记录测试条件、跳过项、暂缓异常及未决问题。
6. **整理学习卡片**：按学习层级选用模板，保留关键解释、实际配置和用户提供的原始图像。

流程会跟随学习进度进入，不要求每个电路都走完全部阶段。用户已理解的内容和明确跳过的实验不会反复重讲或强制安排。

## 仿真指导原则

- 根据真实端口连接和供电域确定激励，不从端口名或单张 symbol 猜测极性、位序和电压。
- 指明实际源类型，例如 vdc、vpulse 或 PWL vsource；逐项说明电平、延迟、上升/下降时间、周期、脉宽等适用参数。
- 对使能信号描述具体有效/无效状态和相应电压；未知的电源、负载或逻辑电平先标注未知，不填入伪确定数值。
- 根据要验证的问题选择最小的实验集合。没有仿真器访问权限时，给出可执行的配置并等待实际结果，不声称已经运行。
- 仅在所给条件下判断波形。单一频率跑通不代表最高工作频率或所有 corner 均通过；暂缓问题也不等于验证通过。

## 结论与证据边界

- 端口顺序以 subckt 声明为准，网络关系以实例连接/原理图为准；名称仅作为线索。
- 明确标出来源事实、结构推导、用户描述、已查看的仿真结果和待验证假设。
- 结论受网表版本、测试激励、负载、电源、工艺角和仿真设置约束；未知条件会明确保留。
- 对本地电路资料，应优先在用户提供的上下文中分析，不把专有网表上传到外部搜索或服务。

## 维护

更新流程时，以实际验证过的用户反馈为准；修改工作流后检查 Skill 入口、参考资料和卡片模板之间是否仍然一致。保持核心说明简洁，把按需阅读的细节放在 references/ 中。
