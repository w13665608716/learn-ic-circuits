# 激励配置与证据边界

## 从目标得到配置

为每个选中实验使用“问题—接法—源参数—测量—判据”的小表。已有 testbench 尽量只改必要部分。

| 输入种类 | 具体源选择 | 必须明确的内容 |
|---|---|---|
| 固定电源/偏置 | analogLib/vdc 或明确 DC 模式的 vsource | 数值、参考地、供电域；未知时用符号并询问 |
| 周期时钟 | analogLib/vpulse | 低/高电平、delay、period、rise、fall、width |
| 使能/复位/置位 | vdc（固定状态）或 vsource 的 pwl 模式（切换） | 高/低分别意味着什么、初始状态、有效区间、释放时刻 |
| 数据/模式码 | vdc、vpulse 或 pwl，按实验选择 | 位序、各位值、与时钟的相对时刻 |
| 反馈接法 | 导线 | 删除同节点冲突的独立理想源，说明反馈极性 |

周期由 T=1/f 计算；有限 rise/fall 和 width 的语义按当前仿真器字段确认，不能盲把 width=T/2 视为精确 50% 占空比。未给出实际边沿时，建议值必须标“建议”。差分/CML 等输入须另核共模、摆幅与源阻抗，不能直接套轨到轨时钟。

PWL 给出递增的时间—电压点和单位，使用有限斜坡，并说明是否重复、终止后的行为。通过前后各一点定义保持和切换；数据窗口和初始化时间须足够。只有看到窗口后才按实际字段指导填写；file 字段的含义依当前源模式核实，不能泛化。

把“建议配置”与“用户实际采用且确认的配置”分开。供电未明时不套用曾用电压；负载未知时不称经验电容为实际负载。实际负载来自下级输入、连线/提取寄生及扇出；估计扫描只用于探索。

## 结果判据

- 功能：输出极性、边沿触发、频率比、等待顺序、停止/清零是否符合连接推导。
- 时序：明确起点、终点及电压阈值。边沿时间（如 10%–90%）不同于传播延迟（如 50%–50%）。先排除启动窗口再测稳态。
- 高频：检查漏翻转、多翻转、错误分频、未到有效电平、窄脉冲和数据错误。幅度/占空比不完全理想不自动等于失败，需对照接收要求。
- 极限：单个目标频率通过只说明该条件能工作；最高频率须搜索边界、定义失败判据，并记录 PVT、负载、边沿、仿真精度和可重复性。
- 数据可信度：截图只支持可见波形和近似读数；精确时间用游标或原始数据；用户口述数值标为用户报告。

没有仿真环境时不要声称运行。没有模型、负载或 PVT 信息时限制结论，不阻止已有功能学习收尾。用户暂缓 corner 异常时，保留“异常已观察、原因未定、暂缓”的记录。
