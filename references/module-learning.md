# 模块级学习

## 讲解顺序

1. 从顶层端口与实例连接识别实际输入、输出和供电域。仅凭 subckt 端口列表不能保证方向。
2. 说明输出的实际用途，以及使能、选择码、复位分别控制哪个行为。用一个输入变化过程解释用途。
3. 沿输入到输出的路径分组：缓冲、同步、延时/计数、门控、确认等；仅对实际存在的组展开。
4. 分清控制路径与信号路径。例如计数器可能只决定何时放行原时钟，不代表输出在分频。
5. 用状态表说明关闭、等待、有效、重新初始化等实际存在的阶段；指出输出与 ACK 等状态信号为何可能不同步。
6. 只有深入子单元会解决当前理解障碍时下钻。层级数量不作为学习深度目标。

## 最小验证选择

- 使能型电路：选择一次开启/关闭检查；明确起算事件和观察边沿。
- 可编程等待：比较选择码改变后的相对延迟；确认总线高低位次序，排除同步/传播固定开销后再解释计数。
- 独立检测与主输出：按连接判断是否应独立工作，不从名字推断。
- 用户要求某频率可用：在确认供电、输入边沿和负载后测试目标点；记录条件，不自动把通过频率叫最高频率。
- 启动异常：区分初值、复位、供电爬升、时钟开始时刻及正常运行；未定位则标明待查。

## 完成标准

用户能说明模块何时产生什么输出，关键控制如何改变行为；已选择的验证得到有范围的结论，或明确跳过。不要强制学习所有子模块、所有计数器晶体管或完整时序签核。
